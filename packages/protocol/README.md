# Shared protocol contracts

Wrapper for versioned contracts shared across surfaces:

- Hermes Unix-socket NDJSON control protocol.
- Muse MCP tool names and result shapes.
- Hermes host HTTP/event bridge payloads.
- Android notification payloads.
- Glasses/phone WebMCP approval tool payloads.
- Audit record and frame/screenshot receipt fields.

No schema is copied here until the selected demo freezes the exact payloads.
