# Walkaway glasses Web App

Meta Ray-Ban Display Web App (600x600, WebMCP). See the root [README](../README.md) for the full story, run commands, and status, and [docs/INSTALL_PIXEL.md](../docs/INSTALL_PIXEL.md) for hardware install.

Tools: walkaway_start_task, walkaway_read_status, walkaway_propose_step, walkaway_approve_step, walkaway_reject_step, walkaway_stop_task. Approving executes exactly one proposed step; proposing never executes.
